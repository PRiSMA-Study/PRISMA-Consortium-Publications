# PRISMA Consortium Publications

Welcome to the **PRISMA Consortium Publications Repository**, a collection of scientific publications and research outputs from the **Pregnancy Risk Stratification Innovation and Measurement Alliance (PRISMA) Consortium**.

This repository provides access to research generated through PRISMA and its collaborating study sites and institutions. Publications cover a range of topics related to maternal, pregnancy, newborn, and infant health, as well as methods and approaches developed through the consortium.

## Exploring Publications

Each publication is organized in a separate folder using a shortened version of the publication title and year.

For example:

`Reference and Decision Limits for Redefining Maternal Anemia - Year`

Depending on availability, publication folders may contain:

* Publication details and citation
* Links to the published article or DOI
* Analysis code used for the publication
* Supplementary materials
* Other publicly available resources related to the research

Visitors can browse individual publication folders to explore PRISMA research outputs and access available materials.

## Code and Reproducibility

Where analysis code is publicly available, it will be included within the corresponding publication folder.

Each publication folder will include its own **README** describing the coding structure for that specific analysis. This may include the purpose of individual scripts, the recommended order for running the code, required packages or software, expected inputs and outputs, and any additional instructions needed to understand and utilize the code.

Because analytical methods and coding workflows may differ across publications, users should refer to the README within each publication folder before running or adapting the code.

## Data Availability

**PRISMA study data are not included in this repository.**

Access to PRISMA data is available through a formal collaboration request and is subject to completion of the applicable PRISMA data access and collaboration processes. The code shared in this repository is intended to provide transparency regarding the analytical methods used in PRISMA publications but does not provide access to the underlying study data.

Researchers interested in accessing PRISMA data should follow the established PRISMA collaboration request and approval process.

## For PRISMA Collaborators

PRISMA collaborators adding a new publication should create a folder using:

`Short Publication Title - Year`

Add the relevant publication materials and include a README with the **full title, authors, year, journal or conference, publication type, PRISMA site(s), DOI or link, and publication status**.

For analysis code specifically, the publication README **must** describe:

* The organization and purpose of the code files
* The order in which scripts should be run, where applicable
* Required software, packages, or dependencies
* Required inputs and expected outputs
* Any important instructions for running or adapting the analysis

**Do not upload PRISMA study data, participant-level data, or other restricted datasets to this repository.**

Please check that the publication has not already been added, and upload only materials appropriate for public sharing.

This repository will continue to be updated as new PRISMA Consortium research becomes available.
